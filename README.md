# US30 15m Trading Strategy (Experimental)

This repo contains an experimental trading strategy I built in TradingView using Pine Script for the US30 on the 15-minute timeframe.

I built it mainly to learn how to translate trading ideas into clear, rule-based logic and understand how backtesting actually works.

## Overview
The strategy uses a set of predefined conditions to generate long and short trade signals. I tested different variations using TradingView’s backtesting tools to see how small logic changes affected historical performance.

The main takeaway from this project was learning the limitations of backtesting and how easy it is to overfit strategies if you’re not careful.

## Tech Stack
- TradingView
- Pine Script

## What This Project Helped Me Learn
- How to turn subjective trading ideas into objective rules  
- How TradingView backtesting works (and where it falls short)  
- Basic automation concepts for trade execution  
- Why risk management matters more than win rate  

## Notes
This project is experimental and educational. Backtested results don’t guarantee future performance, and this strategy isn’t something I’d blindly run live without further work.
